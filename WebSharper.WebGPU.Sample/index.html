What this sample exercises

  • navigator.gpu: requestAdapter, getPreferredCanvasFormat, wgslLanguageFeatures.
  • GPUAdapter: info, features, limits, isFallbackAdapter, requestDevice.
  • GPUDevice: buffer/texture/pipeline/bind-group creation and the default queue.
  • Graphics: shader modules, render pipelines, bind groups, uniform buffers, render passes, draw.
  • Compute: storage buffers, compute pipelines, dispatchWorkgroups, copyBufferToBuffer, mapAsync/getMappedRange.
